# Contract: ダッシュボードの「提供時間モデル」タブ（UI）

利用者から見える振る舞いの契約。既存の 6 ページの表示・操作・既定ページは変えない（SC-004）。

## 1. ページの登録（`DashboardWorkspace.tsx`）

| 項目 | 値 |
|---|---|
| `SECTIONS` での位置 | 末尾（7 番目。「25年度比較」の後） |
| `id` | `"model"` |
| `name`（ナビ・見出し・狭い画面の選択欄） | 提供時間モデル |
| `description`（広い画面のナビの補足） | stack杯数で提供時間を当てはめ |
| `icon` | `ChartSpline`（lucide-react 0.453 にある） |
| 既定のページ | 変えない（`"sales"`） |
| 矢印キー | 既存の処理のまま、7 ページを循環する |
| 表示条件 | 日付・開始・終了・**集計間隔**（`showInterval` に `"model"` を足す） |

本文の分岐の順序は既存のまま次のとおりにする。新しいページの描画は 3 番目より後になる。

1. 表示条件が不正（未来・逆転）なら、既存のエラー文を出して図表を隠す。
2. 注文が未受信なら、既存の `LoadingState`（「注文データを読み込んでいます」）を出す。「0 件」とは出さない。
3. `section === "model"` なら `<StackModelSection …/>` を出す。

## 2. 表示の構成（上から順に）

1. **係数**（FR-008・FR-010・FR-016）
   - 主役は 3 つの値。値は有効数字 3 桁で出し、その下に平易な言葉の名前を添える。
     - 空いているときの提供時間 c1（分）
     - 待ちが伸び始める杯数 a1（杯）
     - 1 杯増えるごとに延びる時間 b（分/杯）
   - 補助として、b1 と N = 6 人（固定）を出す。
   - それぞれの横に、固定モデル（雙峰祭2025・レジの予測と同じ）の値を並べる。
   - 件数は「当てはめ n 件・未完了 n 件・取消 n 件・除外（時刻の逆転）n 件」と出す。
   - 当てはめの時点として「最後に反映した打刻 HH:MM:SS」を出す。
   - 折り畳み「モデル式と定義」に、式 `max(b × (stack − a1) + c1, c1)`・`b = b1 + c1 / N`、stack と提供時間の定義、当てはめ方（非線形最小二乗・等重み・外れ値を除外しない・初期値 3 候補・最低 20 件）、反復の回数を書く。
2. **いまの状況**（FR-009）
   - いまの stack（杯）・未完了の注文の件数・いちばん古い未完了の経過時間（分）
   - いま注文したときの予測を 2 つ（当てはめ・固定モデル）
   - 見出しは、営業中なら「いまの状況（HH:MM）」、期間の終わりが過去なら「期間末（HH:MM）時点の状況」とする。
3. **警告**（FR-015）。該当するときだけ出す。
4. **散布図**（FR-011）。凡例は「実測（注文）」「この当てはめ（実線）」「固定モデル（破線）」「折れ点 a1」とする。
5. **精度の要約**（FR-012）と **stack の区間表**（FR-013）
6. **係数の推移**（FR-014）。a1・c1・b の 3 つのグラフ。固定モデルを基準線にする。

## 3. 表示の状態

| 状態 | 条件 | 係数の欄 | いまの状況 | 散布図・精度・区間表 | 推移 |
|---|---|---|---|---|---|
| 当てはめ済み | `fit.ok` | 数値と固定モデル | 両方の予測 | 全部 | 点と欠け |
| 件数不足 | `reason = "insufficient"` | 「当てはめ不能（件数不足）：あと k 件で当てはめます」と固定モデルの値。当てはめの数値は出さない | 固定モデルの予測だけ | 点（あれば）と固定モデルの曲線。精度の「この当てはめ」の行は「当てはめ不能」 | 点が 1 つも無ければ「当てはめ可能な時点がまだありません」 |
| 収束しない | `reason = "no-convergence"` | 「当てはめ不能（収束しない）」。数値は出さない | 固定モデルの予測だけ | 件数不足と同じ | 同上 |
| 未受信 | `!isOrdersLoaded` | ページの前で `LoadingState` | – | – | – |
| 期間の誤り | `!selectedWindow` | ページの前で既存のエラー | – | – | – |

## 4. 文言（固定）

- 常時の注意文は置かない。モデルと当てはめの限界は、利用者が承知しているものとする。
- **警告**（条件に当たったときだけ。事実を述べ、解釈や留保は付けない）:
  - a1 の範囲外: 「折れ点 a1（x.xx 杯）が、当てはめたデータの stack の範囲（min〜max 杯）の外です。」
  - b ≤ 0: 「傾き b が 0 以下です。」
  - 外挿: 「いまの stack（n 杯）は、当てはめに使った最大（max 杯）を超えています。」
  - 前日以前の未完了: 「前日以前に受け付けて、まだ提供可能になっていない注文が n 件あります。いまの stack には数えていません。」
- **表示範囲外**: 「表示範囲外に n 件（縦軸 y 分超）。当てはめには含めています。」

## 5. アクセシビリティと単位（FR-019）

- すべての軸に、対象と単位を付ける。
  - 「注文時点の stack（杯）」「提供時間（分）」「時刻（JST）」「a1（杯）」「c1（分）」「b（分/杯）」
- 系列は色だけで区別しない。線種（実線・破線）、点の形、凡例の文字を併用する。
- 各グラフの下に、既存の `ChartValues`（「グラフの数値を表で見る」）を置く。ホバーできない端末やキーボードでも全部の値を読めるようにする。
- 散布図の点は、ホバーかタップで Tooltip を出す。内容は「注文 #番号・stack n 杯・実測 x.x 分・予測 y.y 分（固定 z.z 分）」とする。
- 担当者名（指名）と注文コメントは、どこにも出さない（FR-018）。
