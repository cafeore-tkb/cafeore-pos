# Illustratorでの編集

各ページのSVGをIllustratorで開いてください。本文・見出し・注記は文字として保持し、ひとまとまりの段落は1つのSVG text要素にまとめています。折り返し行はtspanです。画面・カード・アイコンの見本は画像として埋め込んでいます。

完全なNoto Sans JPフォントをインストールしてください。
https://fonts.google.com/noto/specimen/Noto+Sans+JP

SVG内のフォントと同梱のTrueTypeは、表示に必要な499文字に絞ったものです。新たな文章の編集には完全なフォントを使ってください。SIL OFL 1.1のライセンスを同梱しています。

SVGのブラウザー表示、文字保持、段落構造、画像埋め込みを確認しました。Illustrator実機での読み込み・編集は未確認です。読み込み後に文字がエリア内文字になるか、行単位へ分かれるかは実機で確認してください。PDFは閲覧用で、段落単位の編集にはSVGを優先します。

この資料の画面はiPad相当のブラウザーで撮影しています。実機iPad・実プリンターの検証ではありません。CaOS関連実装PR 10本を統合した確認版を対象とし、mainへのマージ・本番デプロイは行っていません。
