# マスターシート（CaOS）の使い方

このマニュアルは、注文を抽出担当者に割り当てる人向けです。主に「D」の画面を使って説明します。

マスターシートでは、**どの注文を、誰が、どの順番で淹れるか**を管理します。画面に出る「CaOS」は、この機能の名前です。

## 1. 最初に覚えること

1. **空いている列に注文を置くと、抽出のタイマーが始まります。** 担当者が実際に淹れ始められることを確かめてから置いてください。
2. **✓を押すと、今の抽出が終わり、次の待機カードのタイマーが始まります。** 現物のコーヒーと、次の担当作業を確認してから押します。
3. **「抽出を終える」と「お客さんに提供した」は別です。** 準備完了・提供済みの記録は、提供画面で行います。

画面の操作は、ほかの端末にも共有されます。自分の画面で配置を変えると、ほかの人が見ている盤面も変わります。

### このマニュアルで使う言葉

| 言葉 | 意味 |
| --- | --- |
| 注文番号 | お客さんの注文を見分ける番号。「#012」は12番の注文です。 |
| カード | 一緒に抽出する1杯または2杯をまとめた表示です。1つの注文が複数のカードに分かれることもあります。 |
| ドリッパー | この画面では、器具ではなく**抽出を担当する人の枠**を指します。1st〜6thの6枠があります。 |
| 未割当 | まだ担当者を決めていない抽出カードです。Dの画面では、右側の「注文内容」に並びます。 |
| 待機・未着手 | 担当者は決まっていますが、まだ抽出を始めていない状態です。 |
| 抽出中 | 抽出のタイマーが動いている状態です。 |
| 未提供 | お客さんへの提供が済んでいない注文です。抽出が終わっている注文も含みます。 |

**「未割当」と「未提供」は違います。** 全部割り当て終わっていても、まだお客さんに渡していなければ「未提供」に残ります。

## 2. 画面を開く・営業前に確かめる

1. POSのトップページからCaOSを開きます。
2. 画面上部の「管制盤」を選び、表示切替の「D」を押します。
3. 各列の担当者名が、実際に作業する人と合っているか確認します。
4. 上部の注文データの接続状態と、ラベルプリンターの接続状態を確認します。
5. 「テストの盤面です」という帯が出ている場合は、練習用の画面です。本番で使うときは「本番に戻る」を押します。

本番で操作する画面と、見るだけの画面は入口が違います。

| 用途 | 画面の場所 | できること |
| --- | --- | --- |
| 注文を割り当てる・抽出を進める | `/master-sheet` | このマニュアルの操作を行います。 |
| 盤面を別の端末やモニターに映す | `/master-sheet/view` | A・C・Dを切り替えて見られます。割当や抽出の操作はできません。 |
| お湯を持って回る人が確認する | `/master-sheet/libero` | 抽出中の担当者と経過時間を確認します。 |

割当のボタンが出ないときは、まず閲覧専用の画面を開いていないか確認してください。

### 指の操作の基本

| 操作 | 指の動かし方 |
| --- | --- |
| 押す（タップ） | 指を動かさず、軽く1回触れて離します。 |
| 長押し | カードに触れたまま、指を動かさず少し待ちます。詳細などの画面が開きます。 |
| ドラッグ | カードに触れたまま指を動かし、移動先で離します。 |
| スクロール | 一覧の表示範囲を動かします。カードをつかまないよう、スクロールバーかカードのない場所を使います。 |

## 3. D画面の見方

### 3.1 左側の表

横の列は1st〜6thの担当者、縦の行は注文番号です。見出しの1〜6が、それぞれ1st〜6thに対応します。新しい注文ほど下に並びます。

- **担当者の名前**：その列で作業する人です。番号と名前を両方確認します。
- **カードの注文番号と杯数**：何番の注文を何杯淹れるかを表します。商品名も確認してください。
- **「3rd 2番目」などの札**：3rdの担当者が、2番目に淹れるカードという意味です。
- **緑の囲み**：抽出中のカードを示します。
- **薄く残る行**：その行の抽出を終えたあとも、注文番号の位置は変わりません。完了したカードはDの表から消えます。
- **「総杯数」**：表に割り当ててある杯数です。注文全体の杯数より少ない場合は、注文の杯数も併記されます。

**Dの表の上下の位置だけで、淹れる順番を判断しないでください。** 行は注文番号順です。同じ担当者の抽出順は、カードの「抽出中」「○番目」の札で確認します。

同じ注文が複数のカードに分かれていても、番号は同じです。注文を選ぶと、同じ注文に関係するカードが黄色い枠で示されます。

### 3.2 右側の「注文内容」

「注文内容」には、まだ担当者へ割り当てていないカードが並びます。割り当てたカードは右側から消え、左の表へ移ります。

- 原則として、注文番号の小さいものから並びます。
- 入れ直しのカードは先頭側に出ます。「緊急」の札と理由を確認してください。
- 受け付けてから5分以上たっても未割当のカードには、「待ち ○分」の札が付きます。
- カードの上を指で動かすと、カードをつかんで移動する操作になります。一覧を上下に動かしたいときは、右端のスクロールバーか、カードのない場所をなぞります。

### 3.3 「注文内容」と「未提供」のタブ

| 表示 | 読み方・使い方 |
| --- | --- |
| 「注文内容」の番号 | 未割当の中で、いちばん小さい注文番号です。 |
| 「○件 ○杯」 | 注文の数とカップの数です。1件で複数杯あることがあります。 |
| 「NEXT→2nd」など | 次のコーヒーを最も早く始められる見込みの担当者です。自動で割り当てられるわけではありません。実際の手元の状況も確認します。 |
| 「未提供」の番号 | 未提供の中で、いちばん小さい注文番号です。 |
| 「最長 ○:○○」 | 未提供の中で、最も長く待っている注文の受付からの経過時間です。横の最小注文番号とは、別々に集計した表示です。 |
| 赤い丸の数字 | この端末でまだ見ていない、長時間待っている注文や新しいコメントの知らせです。未提供の総件数ではありません。 |

「注文内容」が10注文以上になると、そのタブの数字が赤くなります。最長未提供時間は15分を超えると赤くなり、20分を超えると点滅します。端末の設定で、点滅しない場合もあります。

「未提供」を押すと、注文ごとの経過時間と現在の状態を確認できます。15分以上待っている注文には、時間超過の印も付きます。確認したい注文の行を押すと、表の該当注文が選ばれます。

タブを開いて赤い通知の丸が消えても、注文を提供済みにしたことにはなりません。

### 3.4 担当者の状態

| 表示 | 意味 | 確認すること |
| --- | --- | --- |
| 空き | 抽出中・待機中のカードがありません。 | 担当者が実際に次の抽出を始められるか確認します。 |
| 待機 | カードはありますが、抽出を始めていません。 | 待機の先頭を確認し、必要なら▶で始めます。 |
| 抽出中／まもなく | 抽出のタイマーが動いています。 | 現物の進み具合を確認します。 |
| 継続中 | 予定時間を過ぎても完了の操作がされていません。 | 抽出中なのか、✓の押し忘れなのかを確認します。 |
| 要確認 | 予定時間を2分以上過ぎています。 | 入れ忘れ・完了操作の押し忘れがないか、担当者に確認します。 |
| 指名 N | その担当者を指名した未割当のカップがN杯あります。 | 指名先と杯数を確認して割り当てます。 |

「空き」は、担当者の名前が未登録という意味ではありません。担当者名がない場合もあるので、営業前に名前を確認してください。

予定時間は、1杯のカードで5分、2杯のカードで6分です。**時間が来ても、自動では完了しません。**

## 4. まず1枚、割り当ててみる

例として、右側の「注文内容」にある「#012・1杯」を3rdへ割り当てます。

1. カードの注文番号・商品名・杯数・指名の有無を確認します。
2. 右側の「#012」のカードを、指を動かさずに1回押します。
3. 左の表の同じ注文番号の行に、置ける列の「ここに配置」が表示されます。
4. 3rdの列にある「ここに配置」を押します。
5. 右側からカードが消え、3rdの列へ移ったことを確認します。
6. 「抽出中」か「○番目」の札を見て、いつ始めるカードになったかを確認します。

3rdの列に何もなければ、置いた時点で抽出が始まります。すでに抽出中・待機中のカードがあれば、原則としてその列の最後に入ります。

指名のあるカードでは、指名先以外の列には配置できません。思った列に置けないときは、指名の札を確認します。

ドラッグでも割り当てられます。慣れるまでは、「カードを押す → ここに配置を押す」の順で操作してください。

## 5. 抽出を始める・終える

### 5.1 抽出を始める

空の列への割当では、配置と同時に抽出が始まります。

カードに手の印が付いていて、まだ始まっていない場合は、次のようにします。

1. 担当者がそのカードを淹れ始められることを確認します。
2. 表のカードを押して操作ボタンを出します。
3. ▶を押します。
4. 「抽出中」に変わったことを確認します。

▶が出るのは、その担当者の前の抽出が終わり、待機の先頭になったカードです。前の抽出が残っている場合は、先にその状況を確認してください。

### 5.2 抽出を終える

1. 担当者に、そのカードのコーヒーが淹れ終わったことを確認します。
2. 抽出中のカードを押します。
3. ✓を押します。
4. 完了したカードが表から消えたことを確認します。
5. 次の待機カードがあれば、そのカードが抽出中に変わったことを確認し、担当者と作業を合わせます。

開始から1分未満は✓が出ません。1分以上でも、予定より早い終了では確認が出る場合があります。注文番号と実物を確かめてから進めてください。

列の担当者名の横に「次へ」ボタンはありません。抽出を進めるときは、対象のカードを押して✓を使います。

### 5.3 抽出完了と提供の記録を分ける

| 状態 | 何を確認した記録か | 操作する場所 |
| --- | --- | --- |
| 抽出完了 | 担当者がコーヒーを淹れ終わった | マスターシートのカードの✓ |
| 準備完了 | お客さんへ出せる準備ができた | 提供画面 |
| 提供済み | お客さんへの提供が済んだ | 提供画面 |

**マスターシートの✓だけでは、準備完了・提供済みにはなりません。** 反対に、提供画面で状態を変えても、マスターシートの抽出は自動で完了しません。

## 6. カードのボタンを読む

表のカードを押すと、そのときに使えるボタンがカードの上に出ます。もう一度カードを押すか、外側を押すと閉じます。

別のカードを選んでいて、表のカードが統合相手として示されている場合は、押すと統合されることがあります。操作メニューを開きたいときは、先に「解除」で選択を外してください。

下の記号は説明用です。PDFでは、実際の画面のアイコンと合わせて確認してください。

| ボタン・印 | 何をするか | 主に表示されるとき |
| --- | --- | --- |
| 1〜6 | 別の担当者へ再割当します。通常は移動先の列の最後へ入ります。 | 割当済みで、まだ抽出を始めていないカード。現在の列の番号は出ません。 |
| ▶ | 抽出を始めます。 | 前の抽出がなく、待機の先頭になったカード。 |
| ✓ | 今の抽出を終え、次の待機カードを始めます。 | 抽出開始から1分以上。 |
| 手の印 | 抽出開始を取り消し、未着手に戻します。 | 抽出開始から1分未満の操作ボタン。 |
| 緊急の印 | 入れ直すカップを選ぶ画面を開きます。 | 抽出開始から1分以上のカード。終わったカードが見えるAでも使えます。 |
| 吹き出し | コメントを開きます。 | その注文にコメントがあるカード。 |
| × | カードを担当者の列から外し、未割当に戻します。 | まだ抽出を始めていないカード。 |

**カードの下に小さく出る手の印は、ボタンではありません。** 「このカードはまだ抽出を始めていない」という目印です。

### ×や「解除」を押す前に、場所を確認する

| 場所 | 意味 |
| --- | --- |
| カードの操作ボタンの× | そのカードを未割当に戻します。注文のキャンセルではありません。 |
| パネルの見出しの× | パネルを閉じます。 |
| 選択中の「解除」 | カードの選択を外します。直前の割当や抽出を取り消すボタンではありません。 |
| 「未送信」の一覧の× | まだ送っていない操作を破棄します。通常の操作を戻すためには使いません。詳しくは「通信・印刷で困ったとき」を参照してください。 |

## 7. 割当先・順番を直す

### 7.1 別の担当者へ移す

まだ始めていないカードは、カードを押して1〜6の番号を選ぶと再割当できます。自分が今いる列の番号は出ません。

表のカードを別の担当者の列へドラッグして移すこともできます。

- カードをドラッグするときは、押したまま指を動かし、置きたい場所で離します。
- カードのないところへ置くと、その列の最後へ入ります。
- 移動先が空の列なら、その場所で新しく抽出が始まります。

### 7.2 同じ列で順番を変える

1. 動かすカードをつかみます。
2. 移動先のカードの、左側または右側へ持っていきます。
3. 「#○○○の前へ」「#○○○の後ろへ」の案内を確認します。
4. 目的の案内が出ているところで指を離します。

中央に重ねると、順番変更ではなく「統合」になる場合があります。指を離す前の案内を確認してください。

抽出中のカードの前へ入れると、入れたカードの抽出が始まり、もともと抽出中だったカードは待機へ戻ります。実物の作業を動かしてよいか、担当者と確認してから操作します。

長押しで開く詳細から、移動先や位置を選ぶ方法もあります。

### 7.3 未割当に戻す

まだ抽出を始めていないカードは、カードを押して×を選ぶと未割当に戻せます。

抽出中のカードを含め、表のカードを右側の「注文内容」へドラッグして戻すこともできます。チャットが開いていても、表のカードをドラッグし始めると右側が注文一覧に切り替わり、戻せるようになります。

戻したあとは、右側に出た注文番号・商品・杯数を確認してください。抽出中だったカードを戻すと、抽出開始の記録も解除されます。元の列に待機カードが残っていても、この操作だけでは次の抽出は始まりません。

### 7.4 抽出中のカードを動かすとき

抽出中のカードを動かすと、開始時刻が変わることがあります。

- 空の列や、別のカードより前にある抽出の先頭へ入れると、その時点から始め直します。
- 待機の位置へ入れると、そのカードの開始時刻を取り消して待機に戻します。
- 同じ列の抽出中カードを後ろへ下げると、先頭になった待機カードの抽出が始まります。

画面のタイマーと、実際に淹れているコーヒーが食い違わないよう、操作後は担当者と確認してください。

### 7.5 間違えて押したとき

「解除」は元に戻す操作ではありません。移動の間違いはカードを元の列や順番へ移して直します。

開始から1分未満の押し間違いは、手のボタンで未着手に戻せます。完了してしまったカードを、Dの表から単純に元へ戻すボタンはありません。表示されなくなった場合は、担当者と現物を確認し、必要に応じて運営担当者へ相談してください。

## 8. 同じ商品を2杯まとめる・分ける

同じ商品を1杯ずつ淹れるカードは、1枚の2杯カードにまとめられます。これを「統合」と呼びます。別の注文番号のカードもまとめられますが、注文番号はそのまま残ります。

### 8.1 まとめる

1. 2枚の商品が同じで、それぞれ1杯であることを確認します。
2. 一方のカードを、もう一方のカードの中央へドラッグします。
3. 「#○○○と統合」の案内を確認してから離します。
4. できたカードの2つの注文番号と、合計2杯を確認します。

指名がある場合は、指名なしとまとめるか、同じ指名先同士でまとめます。違う担当者への指名が付いた2枚はまとめられません。

抽出中のカードにもまとめられますが、すでに淹れ始めている抽出にもう1杯を加える操作になります。担当者が対応できることを確認してください。開始から時間がたっている場合は、画面にも知らせが出ます。

### 8.2 分ける

- **未割当の2杯カード**：カードを選び、「分ける」を押します。
- **割当済みで、まだ始めていない2杯カード**：カードを長押しし、詳細の「外す」から未割当に戻す1杯を選びます。

抽出中のカードは、この詳細画面の手順では分けられません。担当者と現物を確認し、扱いを決めてください。

分けたあとも元の注文は残ります。これは注文のキャンセルではありません。番号と杯数を確かめ、必要な杯を割り当て直してください。

## 9. 指名・上級生の札を確認する

### 指名

「指名 2nd」のような札があるカードは、指定された担当者にだけ割り当てられます。指名カードは黒い点線の太い枠でも示されます。

指名だからといって、先の注文を自動で追い越すわけではありません。順番を変える場合は、担当者と確認してください。

### 上級生

「★上級生」の札は、上級生が担当する商品です。列の担当者名に付く★と見比べてください。

上級生でない人の列にも画面上は置けますが、警告の札や通知が出ることがあります。**ボタンが押せたことだけで、担当してよいとは判断しないでください。** 指名の条件も確認し、迷う場合は運営担当者に相談します。

## 10. 注文を探す・コメントを読む・返す

### 10.1 注文番号で探す

1. 画面上部の「番号」を押します。
2. 探したい注文番号を入力します。
3. 表示された注文番号・商品・状態・コメントを確認します。

入力を止めると検索され、該当するカードが見える位置へ移動します。見つからない場合は、番号を確認し、「未提供」も見てください。

Dの表から抽出カードが消えていても、準備完了・提供済みなどの状態は検索結果で確認できます。

### 10.2 コメントを読む

注文番号の右側の吹き出しや、カードの操作メニューの吹き出しを押します。

C・Dでは、コメントのある注文を選んだときやコメントを開いたときに、右側の注文一覧がその注文のチャット表示に切り替わります。マスターの発言は右、レジ・提供などの発言は左に並びます。別の未割当カードを選ぶときは、チャットの見出しにある**「← 注文一覧へ」**を押して戻ります。

吹き出しの目印は、新しいコメントを知らせるために使われます。目印が消えても、過去のコメント自体が消えたわけではありません。コメントがある注文は、カードの操作メニューや番号検索から内容を確認できます。

### 10.3 スタンプで返す

チャットやコメント欄の下にある、次のボタンを使います。押すと、その注文にマスターのコメントとして送られます。

| ボタン | 伝えること |
| --- | --- |
| OK | 連絡を確認し、了承したことを伝えます。 |
| 砂時計（待って） | 少し待ってほしいことを伝えます。 |
| 済み | 連絡に対する対応が済んだことを伝えます。 |
| 来て！ | 相手に直接来て、状況を確認してほしいことを伝えます。 |

**「済み」のスタンプを押しても、抽出完了や提供済みにはなりません。** スタンプは連絡であり、注文の状態を変える操作ではありません。

### 10.4 音声や文字で返す

1. 5つ目のマイクのボタンを押し、音声入力欄を開きます。
2. 端末からマイクの利用許可を聞かれた場合は、利用するか確認します。
3. 話した内容が入力欄に入ったら、注文番号と文章を確認します。必要なら文字を直します。
4. 入力欄の右の送信ボタンを押します。
5. コメント欄に追加されたことを確認します。

音声入力が使えない端末や、マイクを許可しない場合は、文字を入力して送れます。

音声入力の小さな欄には「閉じる」ボタンがありません。入力・録音・送信が終わっているときに枠外を押すと閉じます。録音中は同じ場所に出る「停止」で止め、文字入力中は最初の枠外タップで入力を終えます。録音中のマイクは揺れて表示されることがあります。

C・Dのチャット全体を閉じるときは「← 注文一覧へ」を使います。枠外を押してもチャット全体は閉じません。

## 11. こぼした・淹れ直す必要があるとき

「緊急」は、入れ直すカップを追加する操作です。理由と対象の杯を確認して使います。

1. 抽出中の対象カードを長押しして「緊急（入れ直し）」を開きます。抽出開始から1分以上なら、カードの緊急ボタンからも開けます。
2. カードが見つからない、待機中、またはすでに抽出を終えている場合は、上部の「緊急」から注文番号を指定します。
3. 入れ直すカップを選びます。2杯まとめたカードでは、1杯だけか2杯ともかを確認します。
4. 理由を選ぶか入力します。理由は省略もできますが、周りの人が状況を分かるよう、必要な内容を残します。
5. 選んだ杯数を確かめて「○杯を入れ直して刷る」を押します。練習中は「○杯を入れ直す（テストなので刷りません）」と表示されます。
6. 右側の先頭側に出た「緊急」のカードを確認し、担当者へ割り当てます。
7. 本番ではラベルも印刷されます。1杯ごとに、大きく「緊急」と書いたラベルが先に出て、その次がカップのラベル（レジで出るものと同じ）です。番号・商品・対象の杯を確かめて使用します。

緊急の追加だけでは、担当者への割当は終わりません。また、元の抽出中カードを終える操作でもありません。元のカードが残っている場合は、その扱いも担当者と確認してください。

不要な入れ直しを追加してしまった場合は、未割当または待機中の緊急カードを選び、「取り消す」から「緊急を取り消す」と進めます。詳細画面では「緊急を取り消す」と表示されます。表示に従ってもう一度押すと確定するので、対象の番号を確認してください。

**「緊急を取り消す」は、元の注文をキャンセルする操作ではありません。**

## 12. 担当者が交代するとき

担当者名は、時刻になっても自動では変わりません。作業する人が交代したら、画面の担当者も変更します。

### 12.1 次の予定の人へ交代する

列の見出しの「交代 → 名前」は、**押すとすぐその人へ変わります。** 確認画面を開くボタンではありません。表示された名前と実際の交代先が合っていることを確認してから押してください。

「次の人なし」の場合は、予定の登録やこの端末の合言葉の設定を確認します。

### 12.2 別の人を選ぶ・名前を入力する

1. 上部の歯車を押し、「ドリッパー」を開きます。
2. 一覧から、変更する担当者枠の「交代」を押します。
3. 候補を選ぶか、名前を入力して「この名前にする」を押します。
4. ほかの担当者との入れ替えや、担当者なしにする操作もこの画面で行えます。
5. 列の見出しが変わったことを確認します。

予定の候補が出ない場合は、運営担当者にsohosai-shiftの合言葉を確認します。合言葉は端末ごとの設定です。

交代しても、その列にある抽出中・待機中のカードは残ります。現在の抽出と次の作業を、交代する人同士で引き継いでください。上級生の商品が残っている場合は、その担当も確認します。

### 12.3 待機カードをまとめて移す

列の番号を押すと、その列の操作を開けます。「この列の待機 ○件を移す」から、移動先の番号を選びます。

待機カードをまとめて移す操作です。抽出中のカードは移しません。指名のために移動できないカードが残る場合があるので、移動後は両方の列を確認してください。

## 13. 豆の残量・実績を確認する

### 豆残量確認

上部の歯車から「豆残量確認」を開きます。豆ごとの残量と、盤面で待っている杯数を確認できます。

残量はPOSの在庫情報です。棚卸しは、手元の豆を量り、現在の残量を記録することです。入荷は、新たに届いた数量を足す記録です。同じ画面から行えますが、実物の数量と単位を確かめて入力してください。読み込みエラーが出た場合は、残量がゼロになったという意味ではありません。

### 実績

実績はヘッダーには表示しません。テストプレイを終了すると、担当列ごとの抽出量や、同じ注文を複数の担当者に分けたときの仕上がりの差を確認する画面が開きます。仕上がりの差は、同じ注文の最初と最後の抽出がどれだけ離れたかを表します。

練習終了後の売上や提供時間などは、読み込んだ注文と練習の進行による結果です。本番営業の実績とは区別してください。

## 14. 通信・印刷で困ったとき

<!-- 図11：未送信と未印刷の違い、再送ボタンと送信中の表示。 -->

### 14.1 操作が反映されない・「未送信」が出る

1. 上部の注文データの接続状態を確認します。
2. 「未送信 N件」があれば、押して内容を確認します。
3. 接続が戻ったあと、必要に応じて「もう一度送る」を押します。
4. 未送信の件数が減り、盤面が目的の状態になったことを確認します。

未送信は、この端末で操作を保存したものの、まだサーバーへ送れていない状態です。操作直後に自分の画面が変わっていても、ほかの端末へ反映されたとは限りません。

ほかの端末で先に注文が変わった場合など、操作が受け付けられず、盤面が戻ることがあります。表示された理由と現在のカードを確認してください。

**未送信の一覧の×や一括削除は、送る予定の操作を捨てるボタンです。** すでに共有された操作を元へ戻すためのボタンではありません。送信中の操作は削除できません。判断に迷ったら、内容を残したまま運営担当者に相談します。

未送信が残っているときは、端末を替えたり、ブラウザのデータを消したりする前に運営担当者へ確認してください。

### 14.2 「未印刷」が出る・シールが出ない

1. ラベルプリンターの接続状態を確認します。
2. 電源・用紙など、プリンター本体の状態を確認します。
3. 「未印刷」の再送操作や、表示されている再接続の案内に従います。
4. 実際に出たシールを確認します。すでに出ていた場合もあるため、同じ杯に重複して使わないようにします。

この端末からラベルプリンターに刷れないときは、シールは「代理印刷」をオンにしたレジで刷られます（レジのヘッダーのスイッチ）。そのあいだ、画面には「レジで印刷待ち N 件」が出ます。いつまでも減らないときは、レジの「代理印刷」がオンか、レジのラベルプリンターがつながっているかを確認してください。

注文データの通信とプリンターの接続は別です。シールが出ないからといって、入れ直しを作るボタンを何度も押さないでください。先に、緊急カードがすでにできていないか確認します。

プリンター本体の作業は、[プリンターのマニュアル](printer.md)も参照してください。

### 14.3 音が鳴らない

端末の音量と、画面の音の設定を確認します。閲覧画面では「音あり／音なし」を切り替えられます。iPadでは、画面を開いたあとに一度触れるまで音が出ないことがあります。

音だけに頼らず、カードの状態や通知の表示も確認してください。

### 14.4 上部に「キャンセル #○○○」が出た

キャンセルされた注文の知らせです。注文番号を確認し、担当者・レジ・提供の人に、その注文をどう扱うか確認してください。

上部には直近の1件が表示されます。キャンセルの一覧ではありません。この表示が消えたり、カードを未割当に戻したりしても、注文のキャンセルを取り消したことにはなりません。

## 15. A・C・閲覧画面を使うとき

基本となる注文番号・杯数・指名・抽出の状態は共通です。表示方法が違います。

| 画面 | 見え方 | 操作のポイント |
| --- | --- | --- |
| A | 担当者ごとに、横向きの時間軸でカードを並べます。未割当は下側です。 | 未割当カードを選び、担当者の空き枠を押して割当できます。上の時刻の帯を左右になぞると時間を移動できます。 |
| C | 担当者ごとに抽出中・待機のカードを並べ、右側に未割当を表示します。 | 未割当カードを選ぶと出る1〜6のボタンや、ドラッグで割り当てます。 |
| D | 注文番号が行、担当者が列の表です。 | 未割当カードを選び、同じ注文の行の「ここに配置」で割り当てます。 |

Aで過去や先の時間へ移動したあとは、上部の「現在」または「現在に戻る」を押すと、今の時刻に戻ります。時間の表示を動かす操作は、カードの割当先や開始時刻を変える操作ではありません。

Aのコメントは、押したカードの近くなどに小さな枠で表示されます。枠外を押すと閉じます。録音・文字入力・送信中は閉じ方が異なるので、「音声や文字で返す」も確認してください。

### 閲覧専用の画面

`/master-sheet/view`では、A・C・Dを切り替えて本番の盤面を見られます。カードを押したりドラッグしたりしても、割当や抽出の状態は変更できません。スクロールと通知音の切替は使えます。

閲覧画面とリベロビューは、上部の「管制盤」「リベロ」で行き来できます。

### リベロビュー

リベロは、お湯を持って回る人のための画面です。抽出中の担当者について、始めてからの時間を大きく表示します。「経過の長い順」に並べ替えることもできます。

お湯を渡した担当者の行を押すと、その端末では灰色になります。もう一度押すと戻せます。この印はその端末だけのもので、抽出完了・提供済みを記録する操作ではありません。

## 16. 本番前に練習する

<!-- 図12：練習の帯、速度切替、一時停止、本番に戻る。 -->

1. 上部の歯車から設定を開き、「実データテスト」を押します。
2. 過去の注文JSONを読み込み、時間帯と練習時間を選びます。
3. 「テストプレイ開始」を押します。
4. 「テストの盤面です」の帯が出ていることを確認します。
5. 割当・移動・統合・抽出完了・入れ直しを練習します。
6. 終えるときは設定の「テストを終了」で結果を確認するか、「本番に戻る」を押します。

練習は通常より速い10倍速で始まります。帯の速度切替や一時停止を使えます。画面の時間も同じ速さで進むので、開始から1分などの条件も練習の時計で判断してください。

練習の操作は本番の注文や在庫を変更せず、緊急のシールも印刷しません。練習を終えて結果を表示している間も、まだ練習の盤面です。本番を再開する前に、必ず「本番に戻る」を確認してください。
