CARD DICTIONARY

カードの見本を、実物と見比べる

実画面と同じ OrderCard で作った20種類の例。番号・杯数・指名・緊急の印は、色だけに頼らず確認します。

番号と杯数

同じ注文の2杯は1つの番号。複数注文を統合すると番号が複数になり、後ろへ重なった影が付きます。

指名・上級生

黒い指名札は列の指定。★は上級生のみ。赤い上級生札は担当条件の不一致です。

提供済み・完了

「提供済」はお客さんへ渡した状態。薄い点線の完了カードは抽出終了。別の記録です。
商品設定の背景色が付く場合もあります。赤地は緊急、オレンジ系の枠は注文選択。選択を解除しても、割当や抽出は取り消されません。
狭い幅では補助札を省略。指名レーン・提供済みは優先して残し、極端に狭い場合は折り返す。03 / 08

EMERGENCY / REBREW / DISCARD

入れ直しを作る。元の抽出は別に扱う

「緊急を登録」「元の抽出を破棄」「緊急を取り消す」は、それぞれ別の操作です。

① 対象の杯と理由を選ぶ

ヘッダーの「緊急」またはカードの緊急操作から開く。注文番号と対象カップを照合し、抽出ミス・異物混入・ラベル再発行か自由記述を選びます。

② 元の抽出を破棄するときは確認

入れ直しがある元カードにはゴミ箱が出ます。対象番号・商品・杯数を確認して確定。新しい入れ直しや統合相手は残り、次の待機は自動開始しません。

混在は最大2杯通常と入れ直しを同じカードへ統合できます。「緊急1/2」は片方だけが入れ直しです。
ラベル再発行だけなら元のコーヒーを捨てる操作ではありません。破棄候補には出しません。
刷れないとき未印刷を確認。設定済みならレジが代理印刷します。取消済みの緊急は再送対象から外れます。
実物を捨てる判断は現場で確認。画面の破棄は抽出記録を分けて終了する操作。05 / 08
COMMENTS / HANDOFF

番号を選んで、短く確実に伝える

盤面にカードがない注文・提供済みの注文にも、本日の注文番号からコメントを追加できます。

「コメント」→注文番号か最近の注文を選択。入力中の例です。送信先の番号を最後にもう一度確認。

1

ヘッダーのコメント
新着の数字は未確認の知らせ。総注文数ではない。

2

宛先を選ぶ
番号入力か最近の一覧から選択。カードを動かしても宛先は固定。

3

スタンプ・音声・文字
スタンプはタップで送信。音声は内容を確認。自由記述は追加ボタンで送る。

4

送信成功を確認
失敗時は下書きが残る。通信復帰後に確認して再送する。

下書きは最終編集から約3分で消えます。再読込・日付変更・練習開始でも保持をあてにしないでください。
パネルを開いている間は通常の盤面ショートカットを停止。実際の相手への伝達・現物確認も忘れずに。06 / 08
ORDER STOP / SHIFT CHANGE

受付を切り替える。担当者を引き継ぐ

受付の停止と、すでに受けた注文の抽出は別です。担当交代も自動では行われません。

受付中・受付停止中をタップ

状態を読み、確認パネルで停止・再開を確定。ほかの端末で変わった場合は最新状態を再確認します。注文入力・送信・抽出をロックする機能ではありません。

担当者名・交代から選ぶ

番号と名前、上級生の印を確認。予定表は候補で、時刻になっても自動では替わりません。交代しても、その列のカードは残ります。

接続できないとき受付切替は予約・自動再送しません。状態を読み直してから判断。
上級生のみのカード交代後の担当が条件を満たすか確認。赤い警告を見落とさない。
交代の前に口頭確認抽出中の現物、待機の順、入れ直し、未提供の長い注文を引き継ぐ。
閲覧専用・練習中には受付切替操作を表示しない。切替の権限と運営側の合図を確認。07 / 08
RECOVERY / QUICK CHECK

困ったときは、状態を確認して止まる

表示・状況確認すること
「未送信」が残る連打しない。端末内の操作を確認し、接続復帰を待つ。他端末の操作と競合したら最新の盤面を確認。
プリンターが赤い電源・接続・証明書・未印刷を確認。代理印刷の有無をレジへ確認。重複ラベルは現物と照合。
「あとちょっと」・要確認予定超過だけで✓を押さない。淹れ忘れ・押し忘れ・現物を確認して進める。
ボタンがない／押せない閲覧専用画面か、接続待ちか、送信中かを確認。未着手・抽出中・完了では操作が異なる。
赤い通知の数字新着コメント・長時間待ちなどの未確認分。開いて消えても、注文や提供が完了した意味ではない。
別のタブでも開いた操作用は1つのタブにする。別端末へ映すだけなら閲覧専用の入口を使う。
順番や状態が分からなくなったら、勝手に提供済み・破棄にしない。注文番号と現物を照合し、運営責任者へ確認します。

見るだけの入口

リベロ表示。各担当の抽出中・残り・NEXTを確認。割当操作はできません。

毎回、最後に見る4点

  1. 注文番号と杯数は合っているか
  2. 指名・上級生・緊急の条件は合うか
  3. 押すボタンは「開始・終了・破棄」のどれか
  4. 送信・印刷の結果を確認したか
