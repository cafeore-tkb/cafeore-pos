# 呼び出し画面のスクショ（PR 用）

`claude/gallant-fermi-yy927j`（#997 の対応）の PR に貼るスクショだけを置くブランチです。コードは入っていません。マージしないでください。

- `before/`：main（3b3ad540）の呼び出し画面
- `after/`：PR の呼び出し画面

どちらも 1920×1080 で撮り、1280×720 の JPEG に縮めています。注文はモック（WebSocket に流したもの）です。

ファイル名の読み方：

- `d2` / `d3` / `d4`：番号の桁数（3・4 桁は幅のいちばん広い 8・0 で始まる番号）
- `callN`：お呼び出し中の件数、`dripN`：ドリップ中の件数、`prep`：準備中 12 件あり、`noprep`：準備中なし
- `brewed2`：ドリップ中のうち 2 件は淹れ終わって準備完了待ち（ドリッパー無し）
- `twodrippers`：1 つの注文を 2 台で淹れている（「1st・2nd ドリッパー」）
- `cm-dripbandN`：呼び出しが無い間の CM に重ねるドリップ中の帯、`cm-prepbar`：CM に重ねる準備中バー（準備中 14 件）
- `callN-only`：お呼び出し中だけ
